
# 📝 Blog Management System

A full-stack MERN Blog Management System that allows users to register, log in, create, edit, delete, and manage blog posts securely. The application features JWT authentication, MongoDB database integration, responsive UI, and complete CRUD functionality.

---

## 🚀 Features

- User Registration & Login
- JWT Authentication & Authorization
- Secure Password Hashing (bcrypt)
- Create, Read, Update & Delete Blogs
- User Dashboard
- Profile Management
- Search & Filter Blogs
- Responsive Design
- RESTful API
- MongoDB Database Integration
- Protected Routes
- Error Handling & Validation

---

### Frontend

### Backend
